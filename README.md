# SG DLL Injector

A clean and minimal DLL injection utility with a modern dark UI and neon-green theme.

![SG DLL Injector](assets/sg_injector.ico)

## ✨ Features

- 🎯 Select a target process
- 📂 Drag & drop DLL file support
- 🔄 Refresh target process list
- 💉 Execute DLL injection
- 🟢 Dark neon-green interface
- 💬 Discord and YouTube links
- ⚡ Lightweight and simple UI

## 🖥️ Interface

The application uses a dark interface with a neon-green accent for a clean cyber-style appearance.
